# Quickstart: ブログ作成内容の保存

## 目的

`/blogs/new`で入力した下書きを保存・復元できることを確認する。

## 前提

- 既存の認証が利用できる
- Supabaseの接続設定が有効

## ローカル起動

```bash
npm install
npm run dev
```

ブラウザで`/blogs/new`を開く。

## 動作確認

1. 本文と画像を入力して保存する
2. `/blogs/new`を再読み込みし、内容が復元されることを確認する
3. 保存失敗時に編集内容が残り、再試行できることを確認する
4. 画像挿入後に再読み込みし、画像が復元されることを確認する

## テスト

- 単体/結合テストは本機能で追加予定
- 追加後は`npm run test`で実行可能にする
- 画像アップロードにはSupabase Storageのポリシー設定が必要
