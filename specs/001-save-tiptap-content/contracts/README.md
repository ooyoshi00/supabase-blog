# Drafts API 契約メモ

## エンドポイント

- `GET /api/drafts/me` : 下書き取得
  - 200: Draftを返す
  - 404: 下書きが存在しない
  - 401: 未認証

- `POST /api/drafts/me` : 下書き保存（作成/更新）
  - 200: 保存済みDraftを返す
  - 400: 入力不正
  - 401: 未認証
  - 500: 保存失敗

## 画像参照の扱い

- `imageRefs` は本文内の画像参照を保存する
- 参照が失われた場合は本文から非表示にする

## ストレージ

- Supabase Storageの`draft-images`バケットを使用
- バケットに対する挿入/参照のポリシーが必要
